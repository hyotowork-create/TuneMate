# 현장 운영 가이드 (기획서 11장 그대로)

## A. Phase 0 패킷 캡처 체크리스트 (믹서 앞 15분)

준비물: MacBook(Xcode·Wireshark), iPad(DM24.8 앱), USB-C 케이블, 아래 기록표

- [ ] 믹서 현재 씬을 새 번호로 백업
- [ ] iPad를 MacBook에 USB로 연결하고 "이 컴퓨터 신뢰" 승인
- [ ] 터미널 `rvictl -s <iPad UDID>` → rvi0 생성 확인
- [ ] Wireshark에서 rvi0 캡처 시작
- [ ] DM24.8 앱 실행 후 믹서 연결 (연결 과정 기록)
- [ ] 30초 동안 아무것도 조작하지 않기 (유지 신호)
- [ ] CH1 페이더: 최소 → −20 → −10 → 0 → +10 dB, 단계마다 5초 대기
- [ ] CH1 뮤트 켜기 → 끄기
- [ ] CH1 EQ 1밴드: 주파수만 → 게인만 → Q만 각각 변경
- [ ] CH1 → Aux1 센드 변경
- [ ] 메인 페이더 변경
- [ ] 다른 씬 불러오기 → 원래 씬 복원
- [ ] 캡처 저장(.pcapng) → 기록표와 함께 전달
- [ ] `rvictl -x <iPad UDID>` 정리

| 시각 | 조작 | 설정값 |
|---|---|---|
| 예: 14:02:10 | CH1 페이더 | −20 dB |
|  |  |  |

캡처 결과는 `Sources/TuneMateCore/Resources/dm248-protocol.yaml`의 transport/frame/parameters/encodings에 채운다.
각 파라미터는 `verified: true`로 바꾼 것만 앱이 쓴다. 전체 `status: verified` + `firmware:` 확정 뒤 자동 적용이 열린다.

## B. 공간 측정 체크리스트

- [ ] UMIK-1 보정 파일을 앱 설정에 등록 (시리얼 번호로 다운로드)
- [ ] 측정용 빈 채널에 테스트 신호 연결, 채널 EQ·다이내믹스 끄기
- [ ] 메인 출력 EQ를 평탄(0 dB)으로 초기화한 상태를 씬으로 저장
- [ ] 평소 예배 음량에 가깝게 레벨 설정 (장시간 큰 음량 노출 주의)
- [ ] 마이크를 앉은 귀 높이에 두고 좌석 5~8곳 측정
- [ ] 보정 제안 확인 → 적용 → 같은 위치에서 재측정
- [ ] 결과 씬을 새 번호로 저장

## C. 예배 운영 규칙

1. 예배 중에는 예배 잠금 모드만 쓴다. 변경은 음향 담당자가 공식 앱이나 실물 페이더로 한다.
2. 측정과 자동 조정은 리허설 시간에만, 예배 시작 30분 전까지 끝낸다.
3. 모든 변경은 스냅샷이 남은 상태에서만 한다.
4. 이상 동작 시 즉시 앱 연결을 끊고 백업 씬을 불러온다.

## 확인 필요 항목 (기획서 12장) — 채워지면 결정되는 것

| 항목 | 결정되는 것 |
|---|---|
| DM24.8 메인 출력 EQ 종류(PEQ·GEQ)와 밴드 수 | 설정 → 필터 수(AutoEQ maxFilters), `main.eq.*` 밴드 수 |
| 출력 딜레이 유무와 최대값 | `main.delay` 파라미터 추가 여부 |
| 믹서 펌웨어 버전 | 명세 `firmware:` — 불일치 시 쓰기 차단 |
| 네트워크 연결 방식(공유기·고정 IP) | 믹서 탭 IP 입력값 |
| 공식 iPad 앱과 동시 접속 허용 여부 | 리허설 중 공식 앱 병행 가능 여부 |
| 스피커 구성과 출력 번호 | 설정 → 스피커 구성, 보정 적용 대상 출력 |
| 믹서 USB 재생으로 테스트 신호 파일 재생 가능 여부 | 측정 → 스윕 WAV 내보내기 경로 사용 여부 |
| 채널 이름표 | 설정 → 채널 이름표 (AI 맥락) |
